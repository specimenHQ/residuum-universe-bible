## What This Repository Is

This repository provides a durable public record connecting **Residuum Press**, **Wesley F. Black**, the press website, published and announced works, and the public-facing Residuum universe canon.

For the most current book descriptions, publication status, cover art, and purchase links, use the canonical Residuum Press website:

https://residuumpress.com/

If the custom domain is no longer maintained, the intended public fallback is:

https://residuum-press.bwerth32.workers.dev/

The current website source is preserved in `residuum_press_website/`, including individual book pages and machine-readable discovery files such as `robots.txt`, `sitemap.xml`, and `llms.txt`.
